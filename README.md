# JavaScript Problem-Solving Practice (Part 02)

The second part of the JavaScript problem-solving series focused on enhancing algorithmic thinking through functions, loops, string processing, and basic mathematical operations.

## 📁 Repository Overview

Here is a quick breakdown of the problems solved in this repository:

* **`problem01.js`**: Program to count how many times a specific number (e.g., 5) is repeated in an array.
* **`problem02.js`**: Function to count the total number of vowels in a string.
* **`problem03.js` & `problem04.js`**: Functions to search and find the smallest number in an array.
* **`problem05.js`**: Function to calculate the total price of products or cart items.
* **`problem06.js` & `problem07.js`**: Solving array iteration and logic problems using the `for...of` loop.
